## 📦 Open-Source Work

- **[PRL UR5 ROS2](https://github.com/inria-paris-robotics-lab/prl_ur5_ros2)** — ROS 2 setup for a dual-arm UR5 modular platform
- **[Allegro Hand ROS2 Driver](https://github.com/inria-paris-robotics-lab/allegro_hand_ros_v4)** — ROS 2 driver for the Allegro multi-fingered hand
- **[WSG50 Gripper ROS Package](https://github.com/inria-paris-robotics-lab/wsg50-ros-pkg)** — driver and ROS integration for the Weiss/Schunk WSG50 gripper
- **[OnRobot Drivers](https://github.com/inria-paris-robotics-lab/onrobot_ros)** — ROS 2 drivers for OnRobot grippers
- **[Wireless Emergency Stop System](https://github.com/inria-paris-robotics-lab/wireless-e-stop)** — wireless e-stop for lab robot platforms
